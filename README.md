# Измеритель скорости HTTP-загрузки

Python 3.11+ и стандартная библиотека. Внешние зависимости не нужны.

## Запуск

```bash
python3 speedcheck.py 'https://example.com/large-image.jpg'
```

Замените пример URL на адрес существующего большого файла. Можно задать таймаут:

```bash
python3 speedcheck.py 'https://example.com/large-image.jpg' --timeout 60
```

Скрипт выполняет ровно десять запросов последовательно. Каждый запрос полностью
вычитывается блоками по 64 KiB перед началом следующего. Память не зависит от размера
файла. Запрашивается несжатое тело ответа и отключение кеширования.

В консоль выводятся число запросов, суммарный объём тела ответов в байтах,
суммарное и среднее время полного запроса, скорость в MB/s и Mbit/s.
MB/s означает мегабайты в секунду (1 MB = 1 000 000 байт).
Скорость считается как суммарные байты / суммарное время, среднее время как
суммарное время / 10. Измерение включает подключение и чтение всего тела ответа.

При сетевой ошибке, HTTP-ошибке или таймауте скрипт завершается с ненулевым кодом.
Результат зависит от выбранного сервера и размера файла, поэтому отражает скорость
загрузки с этого адреса. HTTP/TLS-заголовки в объём тела ответа не включаются.

## Проверка

```bash
python3 -m unittest -v
```

Тест запускает локальный HTTP-сервер с искусственными данными и проверяет десять
последовательных запросов, точный объём и формулы. Внешние серверы не используются.
